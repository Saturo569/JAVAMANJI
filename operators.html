Java Operators

Operators are used to perform operations on variables and values.

    Arithmetic operators - used to perform common mathematical operations.
    Assignment operators - used to assign values to variables.
    Comparison operators - used to compare two values (or variables).
    Logical operators - You can also test for true or false values with logical operators.
    Bitwise operators

Arithmetic operators: int x = 100 + 50;
Assignment operators: String myName = "Justin";
Comparison operators: int x = 5;
int y = 3;
System.out.println(x > y); // returns true, because 5 is higher than 3
